M30 real strongSwan build

This bundle is the custom M30 patch/workflow. It clones the official strongSwan Android frontend in GitHub Actions, keeps the real charon/libipsec engine, and injects a custom M30 Activity as the launcher.

The password is NOT hardcoded. The server identity pointtoserver.com is internal and not shown as an editable field. Default server is 149.50.208.98 and default username is purevpn0s13269248; both are editable in the UI, with username obscured.
